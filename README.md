# Ring of Fire

An endless top-down arena survival game built as a single self-contained HTML5 file (no dependencies).

**Play it here:** https://bishoppawn1.github.io/ring-of-fire-DS4-0731-v2/

## How to run locally
Open `index.html` directly in any modern browser.

## Controls
- **Move** — `WASD` / arrow keys
- **Dash** (invulnerable) — `Space` / `Shift`
- **Pause** — `Esc`
- Your weapon auto-aims and auto-fires.
